# Revenue vs Demand: A Menu Pricing Analysis Using Tableau

## Problem Statement
The business observes high sales volume across multiple pizza products but is uncertain whether popularity translates into revenue efficiency.  
This project investigates whether revenue performance is driven by demand, pricing, or menu design.

## Tools Used
- Tableau (Dashboarding & Calculated Fields)
- CSV Data (Sales Transactions)
- GitHub (Project Documentation)

## Key Business Questions
- Do high-selling pizzas generate the most revenue?
- Which category–size combinations truly drive revenue?
- Are some popular items suppressing average order value?
- What pizzas generate the most money per sale?

## Dashboard Overview
The dashboard compares revenue, quantity, and revenue efficiency to identify misleading best-sellers and uncover true revenue drivers.
